ГЕВОРК БИЛЬЯРДИНСКИЙ — версия 2.0

1. Распакуй ZIP.
2. На GitHub открой artlevitan-apps/gevork-billiardinsky → Code.
3. Загрузи файлы из распакованного ZIP в КОРЕНЬ репозитория с заменой. Папка app важна, папку .github также включи.
4. Если автоматическая сборка уже работает, можно сохранить старый workflow без изменения.
5. Actions → новая сборка → Artifacts → скачай APK.

ВНИМАНИЕ: прежняя версия партии не совместима с этой версией. Новый матч начнётся с нуля.
