# Геворк Бильярдинский — Pool 8-ball v2.0

**Android TV / Google TV / TCL**. Локальная игра под кнопки стрелок, OK и Назад.

## Установка через GitHub Actions

Распакуйте архив. Загрузите **содержимое архива** в корень вашего репозитория `gevork-billiardinsky` (включая скрытую `.github`). Можно просто заменить существующие файлы. Важно: Github Web Upload может не перенести пустые папки, но они здесь не нужны. Если в вашей текущей GitHub Actions сборка уже работает, можно оставить свой `.github/workflows/build-apk.yml` без изменения.

GitHub Actions → Build Android TV APK → скачать артефакт `Gevork-Billiardinsky-8-Ball-APK` → внутри `app-debug.apk`.

## Управление

- В меню: ↑ ↓, OK.
- В игре: ← → — прицел; ↑ ↓ — боковое вращение (±100%).
- Удержание OK: сила от 0% до 100%, циклический повтор за ~1.85 с; отпускание OK — удар.
- После штрафа: стрелки двигают белый шар, OK подтверждает.
- Перед последним ударом по чёрному: стрелки переключают лузы, OK выбирает.
- Back: пауза / продолжить. Музыка и эффекты выключаются независимо.
- 60 секунд на ход; последние 10 секунд — выделенный таймер и тиканье.

## Правила

Домашние правила восьмёрки: шары 1–7 сплошные, 9–15 полосатые, 8 — чёрный, 0 — биток. Первый правильно забитый цвет определяет группы. Неправильное первое касание, промах без касания борта после контакта или забитый биток дают сопернику право поставить белый шар куда угодно. Неправильно забитая чёрная возвращается на стол вместо немедленного поражения. Победа только за правильную восьмёрку в заранее выбранную лузу после очистки своей группы.

Это упрощение в интересах домашней игры, а не полное воспроизведение официальных WPA-правил.

## Реализация

- WebView с аппаратным перехватом кнопок пульта в `MainActivity.java`.
- Всё содержимое без интернета в `app/src/main/assets/index.html`, `dad.jpg` и `club-lounge.mp3`.
- Физика: импульсы столкновений, сопротивление качению, отскоки от бортов, упрощённая модель бокового вращения. Подсказка: геометрическое предсказание до ближайшего шара/борта и одного последующего сегмента, не полный численный расчёт движения.
- ИИ использует оценку прямых ударов в лузы, линий видимости, срезки и небольшой рандомизации.
- Музыка — оригинальная синтезированная джазовая инструментальная композиция, созданная специально для игры.

## Тесты

Синтаксис JS проверен. APK не собран и не протестирован на реальном TCL в этой среде; дальнейшая проверка на ТВ важна.
